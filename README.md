# Sistema de Trazabilidad, Adopción y Expediente Médico para Refugios de Mascotas

## Descripción del Proyecto
Plataforma integral orientada a organizaciones de rescate y refugios de animales. Permite centralizar la trazabilidad de las mascotas rescatadas, llevar su historial clínico y esquema de vacunación, y gestionar el flujo de adopción (solicitud, evaluación de candidatos y seguimiento post-adopción).

## Objetivo
Demostrar la correcta organización, control de versiones y flujo de trabajo de un proyecto de software utilizando Git y GitHub Projects.

## Herramientas Utilizadas
- **Control de Versiones:** Git y GitHub
- **Gestión del Proyecto:** GitHub Projects
- **Editor de Código:** Visual Studio Code

## Estado Inicial del Proyecto
El proyecto se encuentra en fase inicial de estructura y planificación. Se han creado las carpetas principales del repositorio, la documentación base y el tablero de seguimiento en GitHub Projects.

El trabajo se gestionará mediante un tablero Kanban en GitHub Projects dividido en cuatro columnas: Pendiente, En proceso, En revisión y Completado.
